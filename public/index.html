Copia la clave ahora

⌘

Endpoint MCP

Usa la clave como encabezado Authorization: Bearer TU_CLAVE. Mantén la clave privada; puedes revocarla cuando quieras.

02

Conecta tu asistente

Elige tu cliente y usa el endpoint de arriba. Si tu asistente está en otro dispositivo o en la nube, primero publica la aplicación con HTTPS.

  1. Copia tu clave MCP y reemplaza TU_CLAVE_MCP en el comando.
  2. Ejecútalo en la computadora desde la que usarás Claude Code.
  3. Comprueba la conexión con claude mcp list o /mcp dentro de Claude Code.
Terminal

El comando guarda la clave en la configuración privada de Claude Code. No la compartas ni la subas a Git. Ver guía oficial de Claude Code.

  1. Guarda tu clave en la variable de entorno local FACTURA_MCP_TOKEN usando tu gestor de secretos.
  2. Agrega el bloque siguiente a ~/.codex/config.toml.
  3. Reinicia Codex y comprueba con codex mcp list o /mcp.
config.toml

La variable debe estar disponible para el proceso de Codex. Ver guía oficial de Codex MCP.

  1. En tu cliente, agrega un servidor con transporte Streamable HTTP.
  2. Pega el endpoint y configura el encabezado Bearer con tu clave.
  3. Pide al asistente que liste tus tickets para comprobar la conexión.
Datos de conexión

Tu cliente debe admitir encabezados personalizados o tokens Bearer.

Conexión directa pendiente

ChatGPT requiere OAuth para conectar un MCP con datos privados. Factura Clara usa por ahora claves Bearer personales y todavía no ofrece el flujo OAuth; pegar esta clave en el formulario de ChatGPT no conectará la cuenta.

Mientras tanto, puedes usar Codex, Claude Code o la aplicación web y PWA. Ver requisitos de autenticación de OpenAI.
